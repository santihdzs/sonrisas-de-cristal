# Backend (pendiente)

Todavía no hay backend. La app corre con datos de prueba en memoria.

- Stack planeado: Ktor + PostgreSQL. Kotlin igual que la app, de código abierto y gratuito de operar.
- Autenticación con JWT de acceso y de actualización (refresh), como en la práctica "Avisos".
- Del lado de Android basta con cambiar los repositorios falsos por implementaciones con Retrofit dentro de `AppContainer`; las pantallas y los ViewModels no cambian.
